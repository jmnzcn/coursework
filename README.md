# Coursework

Projects from my graduate studies in Computer Science at the University of Costa Rica (UCR),
kept in one place. Each folder came from its own repository, with its commit history.

| Folder | Course | What it is |
|---|---|---|
| [pf3311-chat-cli](pf3311-chat-cli) | PF-3311, I-2026 | Terminal chat with Gemini: voice input, ElevenLabs voice output, retries, logging, and a Flask web version |
| [pruebas-software-lab](pruebas-software-lab) | Software testing, II-2025 | Three Flask microservices (users, flights, bookings) in Docker Compose. It grew into [flightbooking-qa-copilot-mcp](https://github.com/jmnzcn/flightbooking-qa-copilot-mcp) |

Also from the program, in their own repositories:

- [asesor-agilidad-escala](https://github.com/jmnzcn/asesor-agilidad-escala): an agent that recommends a scaled agile
  framework with an auditable multi-criteria matrix (PF-3872).
- [pf3312_lab](https://github.com/jmnzcn/pf3312_lab): three 3D virtual agents in Unity, with facial expressions and
  lip-sync (PF-3312). It led to [virtual-agent-trust-study](https://github.com/jmnzcn/virtual-agent-trust-study).

These are course deliverables, kept as they were handed in. The projects I maintain are on
[my profile](https://github.com/jmnzcn).
